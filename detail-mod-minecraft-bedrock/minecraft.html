📖 Panduan Instalasi & Bantuan Mod Minecraft PE

💻 Cara Instalasi di PC (Windows Edition) ▼

Bagi Anda pengguna Minecraft Bedrock / Windows, proses instalasi sangat mudah:

  1. Klik tombol Download / Deploy di portal AstroMods untuk mengunduh mod berkas berekstensi .mcaddon atau .mcpack.
  2. Cari berkas tersebut di penyimpanan komputer Anda, kemudian klik dua kali (double-click).
  3. Game Minecraft akan terbuka secara otomatis dan di pojok atas akan muncul notifikasi "Import Started" diikuti "Successfully Imported".
  4. Masuk ke pengaturan dunia Anda (World Settings), cari tab Behavior Packs dan Resource Packs di sisi kiri bawah, lalu aktifkan mod Anda di sana.
  5. ⚠️ PENTING: Pastikan Anda telah mengaktifkan opsi "Beta APIs" dan "Upcoming Creator Features" di menu Experiments Settings dalam dunia Minecraft, agar seluruh fungsi script mod berjalan lancar!
📱 Cara Instalasi di Android (HP & Tablet) ▼

Untuk perangkat ponsel pintar Android, ikuti langkah-langkah di bawah:

  1. Unduh file berkas mod lewat tautan AstroMods.
  2. Buka aplikasi File Manager terpercaya Anda (seperti ZArchiver atau Files by Google).
  3. Cari file mod yang baru diunduh. Jika formatnya masih berupa .zip, Anda wajib mengganti namanya (rename) dengan menghapus teks .zip di akhir agar menjadi .mcaddon atau .mcpack saja.
  4. Ketuk file tersebut sekali, pilih opsi "Open with..." / "Buka dengan..." dan tunjuk aplikasi Minecraft.
  5. Aktifkan resource dan behavior packs di dalam dunia yang Anda buat, dan jangan lupa mengaktifkan fitur eksperimental di pengaturan dunia.
🍏 Cara Instalasi di iOS (iPhone & iPad) ▼

Panduan mengimpor mod di platform Apple iOS:

  1. Gunakan browser Safari untuk mengunduh berkas mod dari AstroMods agar file tidak terkorup selama transfer.
  2. Setelah terunduh, luncurkan aplikasi Files (File) bawaan perangkat Apple Anda.
  3. Buka direktori Downloads (Unduhan), sentuh dan tahan berkas mod tersebut hingga menu melayang muncul.
  4. Ketuk tombol Share (Bagikan), lalu swipe dan cari ikon game Minecraft untuk mentransfer berkas secara langsung ke dalam permainan.
  5. Minecraft akan otomatis diluncurkan dan mengimpor file addon tersebut secara otomatis.
⚠️ Mengatasi Masalah & Error (Troubleshooting) ▼
  • Error: "Duplicate Pack Detected"
    Hal ini menandakan versi mod terdahulu sudah terpasang. Solusinya: Dari menu utama Minecraft utama, kunjungi Settings -> Storage -> Resource Packs atau Behavior Packs, lalu cari nama mod tersebut dan klik ikon tong sampah untuk menghapus berkas lama secara permanen, barulah impor berkas baru yang telah diunduh.
  • Error: "Missing Dependencies"
    Banyak addon membutuhkan kedua file yaitu Resource Pack dan Behavior Pack diaktifkan bersamaan demi visual yang padu. Silakan periksa kembali apakah Anda sudah mengaktifkan kedua jenis paket berkas tersebut di pengaturan dunia Anda.
  • Mod Tidak Berfungsi (Scripts Rusak)
    Pastikan Anda telah mengaktifkan tombol toggle Eksperimental/Experiments di pengaturan dunia. Seluruh mod modern wajib mengaktifkan opsi ini agar program scripts dapat dieksekusi oleh mesin Java/C++ game.
